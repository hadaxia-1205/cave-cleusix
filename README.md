# Cave Cleusix

Site statique de la Cave Cleusix : HTML, CSS et un peu de JavaScript. Aucun build, aucun WordPress, aucun PHP. Les fichiers se servent tels quels.

## Aperçu local

Depuis ce dossier :

```bash
python3 -m http.server 8080
```

Puis ouvrir [http://127.0.0.1:8080](http://127.0.0.1:8080).

Pages :

- `/` — accueil : photo de vigne, puis les quatre vins, puis « L'art du vin, transmis de père en fils. »
- `/histoire.html` — notre histoire
- `/vins.html` — les quatre cuvées
- `/vins/sauvignon-blanc.html`
- `/vins/cuvee-victor.html`
- `/vins/sangiovese.html`
- `/vins/savagnin.html`
- `/contact.html`

## Vins

Sauvignon Blanc (CHF 18.–), Cuvée Victor (CHF 20.–), Sangiovese (CHF 20.–), Savagnin (CHF 15.–). Chaque fiche et la liste des vins affichent un bouton Shopify « Ajouter au panier ». Le paiement se fait dans le panier Shopify.
